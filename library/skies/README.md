# Skies (HDRI)

Panoramic HDR skies used for real lighting and reflections.

- Format: **.hdr** (or .exr), **4K** preferred, 2K OK.
- Wanted: one **dusk / blue hour** sky and one **clear day** sky (warm, open, no buildings close by).
- Where: Poly Haven → HDRIs → Outdoor (e.g. search "dusk", "sunset", "clear sky").
- Files over 25 MB cannot be uploaded through the website: take 2K then.
