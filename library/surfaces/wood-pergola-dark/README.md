# Pergola timber - dark (priority 1)

**What:** Dark stained timber for beams and slats (like the reference picture).

**Where to find:** ambientCG: "Wood" (pick a dark, straight-grain set); Poly Haven: "dark wood", "wood planks".

## What to upload here
Drop the files straight into this folder (GitHub: **Add file → Upload files**).

| Map | Usual file name in the download | Format |
|---|---|---|
| Colour (the photo) | `*_Color`, `*_diff`, `*albedo*` | **JPG** |
| Normal (purple/blue) | `*_NormalGL`, `*_nor_gl*` | **PNG** if offered, else JPG |
| Roughness (grey) | `*_Roughness`, `*_rough*` | JPG or PNG |
| Ambient occlusion | `*_AmbientOcclusion`, `*_ao*` | JPG (optional) |
| Displacement / height | `*_Displacement`, `*_disp*` | PNG (optional) |

- **Resolution: 2K** (2048 px). 4K only for the floor and island top.
- Keep the downloaded names; Claude renames and optimises them.
- If you only download one file, take the **Colour** + **Normal** + **Roughness**.
- Each file must be under 25 MB (GitHub web upload limit).
- More than one candidate? Put each in a subfolder (`option-a/`, `option-b/`) and say which you prefer.
